# RobotAStarSim

Another project I made in my junior year of high school. This one was specifically for my FRC Robotics Team - 4188. I was attempting to make my own pathfinder to eliminate the need to draw out paths it explicit shapes, and instead make a one for all kind of pathing. This algorithm combines A* algorithm on a customizable grid with some of my own math to capture pivot points to put into WPI's TrajectoryGenerator to create the desired trajectoy. Albeit pretty primitive, but elbow grease was involved and I'm somewhat proud of it.
